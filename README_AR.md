# Bankak Demo 2.0 — محاكاة مصرفية تجريبية

## تنبيه مهم
هذا التطبيق نموذج محاكاة مستقل بالكامل. لا يتصل ببنك الخرطوم أو أي بنك آخر، ولا يستخدم واجهات مصرفية حقيقية، ولا ينفذ تحويلات أو شحنات حقيقية. جميع الحسابات والأرصدة والعمليات وهمية ومحفوظة محلياً على الجهاز. لا تدخل بيانات مصرفية حقيقية.

## المزايا الموجودة
- واجهة عربية/إنجليزية.
- إنشاء حساب تجريبي باسم ثلاثي وكلمة مرور.
- رقم حساب تجريبي من 7 أرقام يبدأ بالرقم 2.
- رصيد ابتدائي ثابت قدره 5,000 جنيه سوداني تجريبي.
- شحن تجريبي حتى 3,000,000 جنيه في العملية الواحدة.
- عبارة «استلام أموال تجريبية» في عملية الشحن.
- تحويل بين الحسابات التجريبية المسجلة على الجهاز نفسه فقط.
- إدخال رقم حساب المستفيد والاسم الثلاثي والمبلغ.
- التحقق من الحساب والمبلغ والرصيد قبل التحويل.
- خصم المبلغ من المرسل وإضافته إلى حساب المستلم وسجل المعاملات.
- منع التحويل إلى الحساب نفسه.
- إضافة المستفيدين وحفظهم محلياً.
- تفاصيل الحساب والرقم المرجعي بصيغة 10030 + رقم الحساب + 0001.
- إيصالات خضراء وتفاصيل معاملة وسجل معاملات.
- تصدير الإيصال إلى PDF ومشاركته وطباعته.
- شاشة ملخص عند تسجيل الخروج.
- مؤشر «معالجة» أثناء العمليات وحركة انتقالية بين الشاشات.

## المتطلبات
- Flutter SDK 3.24 أو أحدث (Dart 3.5+).
- Android Studio أو Klencod IDE مع Android SDK.
- Java 17.

## التشغيل
من داخل مجلد المشروع نفّذ:

```bash
flutter doctor
flutter pub get
flutter run
```

إذا كانت ملفات منصة Android غير مكتملة في بيئة التطوير لديك، نفّذ مرة واحدة:

```bash
flutter create . --platforms=android
flutter pub get
flutter run
```

لبناء APK تجريبي:

```bash
flutter build apk --release
```

سيظهر الملف عادةً في:

`build/app/outputs/flutter-apk/app-release.apk`

## ملاحظات تقنية
- لا يوجد خادم ولا مزامنة بين الأجهزة؛ الحسابات الموجودة على جهاز آخر لن تظهر هنا.
- التخزين المحلي مخصص للتجربة فقط وليس مناسباً لحفظ كلمات مرور أو بيانات مالية حقيقية.
- ملفات Android الأساسية مرفقة، لكن يجب أن يكون Flutter وAndroid SDK مثبتين على جهاز البناء.
- لم يتم تنفيذ بناء APK أو اختبار تشغيل على جهاز فعلي ضمن بيئة إعداد هذا الأرشيف.
- الهوية البصرية مستوحاة من لقطات الشاشة المرسلة؛ الشعار النصي بديل مرسوم داخل Flutter وليس شعاراً رسمياً أو أصلاً مستخرجاً من تطبيق بنك.
